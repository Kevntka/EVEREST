# Background Image

## Setup Instructions:

1. **Add your background image** to this folder
2. **Rename it to:** `background.jpg`
3. The login page will automatically use it

## Image Specifications:
- **Recommended size:** 1920x1080 or higher
- **Format:** JPG (for smaller file size)
- **Path used in code:** `/assets/images/background.jpg`

## Fallback Color:
If no image is found, the background will be: `#a8827d` (brownish-pink)
